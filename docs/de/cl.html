AI Coding Literacy

Code Literacy

Generierten Code verstehen

Code Literacy bezeichnet die Faehigkeit, Code zu lesen und zu verstehen. Das ist eine eigenstaendige Kompetenz, die dem Schreiben vorausgeht. Man muss nicht selbst Code schreiben koennen, um LLM-generierten Code zu bewerten. Die Skill-Hierarchie: Run, Trace, Explain, Write.

Theorie Uebungen Vertiefung Ressourcen

Theorie

Kernpunkte

  • Lesen und Schreiben sind getrennte Kompetenzen (Lopez et al., 2008)
  • Skill-Hierarchie: Run, Trace, Explain, Write
  • Auch Experten vermeiden tiefes Verstehen wenn moeglich - partielles Verstehen ist normal
  • 39% der Praktiker finden LLM-Code lesbarer als menschlichen Code
  • Zwei mentale Modelle: prozedural ("Was passiert der Reihe nach?") und funktional ("Was ist das Ziel?")
  • Sie muessen nicht alles verstehen - nur genug, um zu pruefen

Konzepte

Skill-Hierarchie

Run, Trace, Explain, Write: Lesen und Nachvollziehen gehen dem Schreiben voraus

Prozedurales Modell

"Was passiert der Reihe nach?" - Kontrollfluss, Zeile fuer Zeile nachvollziehen

Funktionales Modell

"Was ist das Ziel?" - Zweck verstehen, Eingabe/Ausgabe identifizieren

Delocalized Plans

Code einer Intention ist oft ueber mehrere Stellen verstreut - Navigation erforderlich

Kontrollstruktur

Anweisungen, die den Ablauf steuern (if, for, while)

Bibliothek

Sammlung von vorgefertigtem Code fuer bestimmte Aufgaben

Die Skill-Hierarchie

Stufe 1

Run

Code ausfuehren koennen. Python installieren und starten, ein Skript ausfuehren, Fehlermeldungen erkennen (nicht verstehen).

Stufe 2

Trace

Ausfuehrung nachvollziehen. Welche Zeile wird gerade ausgefuehrt? Was steht in welcher Variable? Welcher Pfad bei einer Bedingung?

Stufe 3

Explain

Zweck erklaeren. Was macht dieser Codeblock? Warum steht das hier? Was passiert bei dieser Eingabe?

Stufe 4

Write

Selbst schreiben. Fuer AI Coding Literacy nicht zwingend erforderlich, aber kleine Anpassungen koennen notwendig sein.

Uebungen

CL-1

Variablen und Datentypen

Die Grundbausteine von Code verstehen.

Lernziele: Variablen als benannte Speicherplaetze verstehen, grundlegende Datentypen unterscheiden, Zuweisungen lesen koennen.

Aufgabe: Lesen Sie Code mit Variablen. Was ist der Wert von objekt["jahr"]? Welchen Typ hat ist_ausgestellt?

CL-2

Kontrollstrukturen lesen

Verzweigungen und Schleifen verstehen.

Lernziele: if/else-Verzweigungen nachvollziehen, for-Schleifen verstehen, Einrueckung als Strukturmerkmal erkennen.

Aufgabe: Welche Ausgabe erzeugt eine Datei-Schleife? Gehen Sie Zeile fuer Zeile durch.

CL-3

Funktionen verstehen

Wiederverwendbare Codeblöcke erkennen.

Lernziele: Funktionsdefinitionen erkennen, Parameter und Rueckgabewerte verstehen, Funktionsaufrufe nachvollziehen.

Aufgabe: Was gibt formatiere_name("Anna", "Weber", "Prof.") zurueck?

Vertiefung

Lesestrategien fuer Code

Top-Down

Erst die Struktur verstehen, dann die Details. Was sind die Hauptfunktionen?

Bottom-Up

Bei Fehlern: Von der Fehlerstelle zurueckverfolgen. Was kam davor?

Dokumentation zuerst

Kommentare, Docstrings, README lesen bevor man den Code analysiert.

LLM als Erklaerer

"Erklaere mir diesen Code" - nutzen Sie das LLM als Tutor.

Was Sie nicht verstehen muessen

Jede Bibliotheks-Funktion

pandas.read_csv() liest CSV, Details egal

Komplexe Algorithmen

Solange Sie wissen, was rein und raus geht

Optimierungen

Ob es elegant ist, ist fuer die Funktion irrelevant

Syntaktischer Zucker

List Comprehensions etc. sind Abkuerzungen

Red Flags beim Lesen

Diese Muster sollten Sie aufmerksam machen:

Keine Fehlerbehandlung

Was passiert wenn die Datei nicht existiert?

Hardcoded Werte

/home/user/data/ funktioniert nur auf einem Rechner

Keine Kommentare

Bei komplexer Logik ein Warnsignal

Sehr lange Funktionen

Schwer zu verstehen, oft fehleranfaellig
