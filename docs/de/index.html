Didaktischer Ansatz

Das Curriculum folgt einem Informed Vibe Coding Ansatz: Experimentieren ist erwuenscht, aber mit wachsendem Verstaendnis fuer das, was passiert. Der intuitive, explorative Umgang mit Code wird nicht ersetzt, sondern durch systematische Reflexion ergaenzt.

Prinzipien

  • Lesen vor Schreiben: Code verstehen ist einfacher als Code schreiben
  • Domaenenwissen als Staerke: Ihr Fachwissen macht Sie zum Experten fuer Ihre Probleme
  • Iteration statt Perfektion: Schrittweise Verbesserung durch Dialog
  • Grenzen erkennen: Wissen, wann professionelle Hilfe noetig ist
