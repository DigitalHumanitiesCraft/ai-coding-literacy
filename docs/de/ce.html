Context Engineering

Kontext fuer LLMs gestalten

Context Engineering bezeichnet die systematische Gestaltung des Informationskontexts, den man einem LLM gibt. Das Kontextfenster ist begrenzt - was man hineinpackt und wie man es anordnet, bestimmt die Qualitaet der Ausgabe. Mehr ist nicht automatisch besser.

Theorie Uebungen Vertiefung Ressourcen

Theorie

Kernpunkte

  • Kontextfenster: GPT-4o 128K, Claude 200K, Gemini 1M Tokens
  • Mehr Kontext ist nicht automatisch besser - Lost in the Middle Problem
  • Bewaehrte Struktur: Rolle, Aufgabe, Infos, Constraints, Format
  • Komprimierung: Relevante Ausschnitte statt ganzer Dateien
  • Beispiele sind oft wirksamer als lange Beschreibungen
  • Projektkonventionen explizit machen

Konzepte

RAG

Retrieval-Augmented Generation - relevante Infos aus externen Quellen abrufen und dem LLM bereitstellen

Lost in the Middle

LLMs verlieren Informationen in der Mitte langer Kontexte - wichtiges an Anfang/Ende

Kontextstruktur

Bewaehrte Anordnung: Rolle, Aufgabe, Informationen, Constraints, Format

Kontextfenster

Die maximale Textmenge (in Tokens), die ein LLM gleichzeitig verarbeiten kann

Destillation

Komplexe Informationen auf das Wesentliche komprimieren

Die 5-teilige Kontextstruktur

Teil 1

Rolle

Du bist ein erfahrener Python-Entwickler mit Fokus auf Datenverarbeitung.

Teil 2

Aufgabe

Schreibe ein Skript, das Excel-Dateien zusammenfuehrt.

Teil 3

Informationen

Eingabedateien: 50 .xlsx im Ordner /data/. Spalten: ID, Name, Datum, Wert. Encoding: UTF-8.

Teil 4

Constraints

Keine externen Dependencies ausser openpyxl. Fehlerhafte Zeilen ueberspringen. Logging in Datei.

Teil 5

Format

Kommentare auf Deutsch. Funktionen mit Docstrings. Ein Skript, keine Module.

Uebungen

CE-1

Kontext strukturieren

Einen Prompt mit der bewaehrten Kontextstruktur aufbauen.

Lernziele: Die 5-teilige Kontextstruktur anwenden, relevante von irrelevanten Informationen trennen, Wirksamkeit vergleichen.

Aufgabe: Vergleichen Sie "Mach mir ein Skript fuer meine Excel-Dateien" mit einem strukturierten Prompt. Dokumentieren Sie die Unterschiede.

CE-2

Wissen destillieren

Einen komplexen Standard so aufbereiten, dass er ins Kontextfenster passt.

Lernziele: Relevante Informationen identifizieren, Kontext strukturiert komprimieren, Wirksamkeit testen.

Aufgabe: Besuchen Sie die Darwin-Core-Dokumentation und destillieren Sie die relevanten Felder fuer eine Museumssammlung. Erstellen Sie ein kompaktes Referenzdokument.
