# Ausblick: Wie weiter?

Drei Pfade zum Vertiefen:

1. **Git/GitHub** – Versionierung und Teilen
2. **Jupyter Notebooks** – Interaktives Arbeiten
3. **Claude Code** – [[LLM]] im [[Terminal]]

---

# Git/GitHub

- Code versionieren (Änderungen nachverfolgen)
- Mit anderen teilen
- Backup in der Cloud

**Einstieg:** GitHub Desktop (grafisch, keine Kommandozeile)

---

# Jupyter Notebooks

- Code + Text + Visualisierung in einem Dokument
- Ideal für Datenanalyse
- Läuft im Browser

**Einstieg:** Google Colab (kostenlos, keine Installation)

---

# Claude Code

- [[LLM]] direkt im [[Terminal]]
- Liest und schreibt Dateien
- Führt Code aus

**Einstieg:** `npm install -g @anthropic-ai/claude-code`
